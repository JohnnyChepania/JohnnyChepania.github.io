# Лендинг ClientRadar

Один экран. Файлы: `index.html`, `logo.png`.

Постоянный бесплатный URL (GitHub Pages) я не могу включить без вашего входа в GitHub.
Когда будет аккаунт:

1. Создайте репозиторий `clientradar` (или `ВАШЛОГИН.github.io`).
2. Залейте содержимое этой папки в корень репозитория.
3. Settings → Pages → Deploy from branch `main` / `/`.
4. Сайт: `https://ВАШЛОГИН.github.io/clientradar/` (или `https://ВАШЛОГИН.github.io/`).

Пока страница отдаётся локальным API: `http://127.0.0.1:8080/`
